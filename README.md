# Zomato Performance Dashboard – Power BI Project

This project presents an interactive Power BI dashboard that analyzes Zomato’s sales, user behavior, and city-wise performance.
The report is built using multiple datasets including orders, restaurants, cuisine types, user activity, and menu categories.

# Project Overview

This Power BI dashboard provides insights into:

 Total sales performance

 Order trends by year and month

 Top-performing cities

 Cuisine-wise sales distribution

 User demographics and activity levels

 Rating behavior and customer engagement

 Veg / Non-Veg performance

 City-level performance metrics

The dashboard is split into three pages:

This project aims to:

Analyze business performance of a food delivery platform

Identify top revenue-driving cities & cuisines

Track user retention (gain/loss analysis)

Support decision-making through interactive data visuals
